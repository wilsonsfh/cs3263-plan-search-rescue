# Report sections: proven-optimal references and the choice of lambda (Yoon)

| File | What it is |
|---|---|
| `sections/optimal-references.tex` | Why we built `pddl/exact.py` (Dijkstra over a reduced state space) and the proof results |
| `sections/lambda.tex` | Penalty = lambda x r_b, the lambda sweep and why lambda = 20 |
| `sections/appendix-optima.tex` | Appendix table of all 45 proven optima |
| `tables/*.tex` | Generated by `python3 report/make_tables.py` from the result CSVs |
| `figures/*.pdf` | Copied from `pddl/lambda-sweep/figures/` (`python3 pddl/lambda-sweep/figures.py`) |
| `references.bib` | BibTeX entries cited by the sections |
| `preview.tex`, `preview.pdf` | Standalone preview of just these sections |

To use in the group report: `\input{sections/...}` (paths are relative to `report/`), add
`booktabs`, `amsmath` and `graphicx`, and merge `references.bib`.

Data behind the tables:
- `exact-timings.csv`: `python3 pddl/exact.py pddl/instances/*.json`, one instance at a time,
  single-threaded (cost, states expanded, seconds). Every cost matches `best_reference.csv`.
- `old_best_reference.csv`: `pddl/results/best_reference.csv` before the exact solver
  (commit before 03ecec4), i.e. the cheaper of the Fast Downward split / no-split plans.
